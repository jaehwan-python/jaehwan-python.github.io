## 📌 About This Project

**Look at Me**는 '김재환'이 프로그래밍, 인공지능, 영어, 항공교통전공공부 등 다양한 분야에서 공부한 내용을 기록하고 공유하기 위해 제작한 개인 학습 아카이브이자 포트폴리오 웹사이트입니다!

단순히 공부한 코드를 보관하는 것을 넘어, 개념을 이해하는 과정부터 문제 해결, 프로젝트 개발 경험까지 체계적으로 정리하는 것을 목표로 합니다.

이 웹사이트는 학습과 함께 지속적으로 확장되는 **Personal Knowledge Archive**입니다.

## ✨ Features

### 🍭 Interactive Homepage

- 핑크색 테마의 3D 스타일 메인 화면
- 풍선껌을 모티브로 한 젤리 형태의 카테고리 UI
- 클릭하면 말랑하게 눌렸다 복원되는 인터랙션
- 스크롤에 따라 자연스럽게 나타나는 캐릭터와 3D 공간 연출
- 다양한 화면 크기를 고려한 Responsive Design

### 📝 Personal To-Do List

- 손글씨 낙서 스타일의 메모
- 할 일 추가, 수정 및 삭제
- `localStorage`를 이용한 자동 저장
- 페이지를 새로고침해도 작성한 내용 유지

### 📚 Learning Archive

- 분야별 학습 카테고리 구성
- 개념 정리 및 코드 실습 기록
- 프로젝트 개발 과정 문서화
- Markdown 기반 학습 노트 관리 구조

## 🎯 Project Vision

**From Learning to Building.**

단순히 AI와 소프트웨어를 사용하는 사람이 아니라, 기술이 작동하는 원리를 이해하고 직접 설계하고 개발할 수 있는 개발자로 성장하는 것이 목표입니다.

이 웹사이트는 그 과정에서 얻은 지식과 경험을 기록하는 공간입니다.

학습한 내용과 개발한 프로젝트를 꾸준히 추가하며, 하나의 개인 지식 저장소로 발전시켜 나갈 예정입니다.
