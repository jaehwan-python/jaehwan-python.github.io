# 1. 패킹(Packing)과 언패킹(Unpacking)

## 1.1 패킹이란?

**패킹(Packing)**은 여러 개의 값을 하나의 자료구조로 묶는 것이다.

Python에서는 쉼표(`,`)로 여러 값을 나열하면 튜플(Tuple)을 생성할 수 있다.

### 예제 코드

```python
v1 = 10, 20, 30

print('v1 : ', v1)
print(type(v1))
```

### 실행 결과

```text
v1 :  (10, 20, 30)
<class 'tuple'>
```

### 작동 원리

```text
v1 = 10, 20, 30
        │
        ▼
  ┌─────────────┐
  │ Tuple 객체  │
  │ (10,20,30)  │
  └─────────────┘
        ▲
        │
       v1
```

**코드 분석**

- `v1`: 튜플 객체를 참조하는 변수
- `10, 20, 30`: 쉼표로 구분한 값
- `print(v1)`: 튜플의 내용 출력
- `type(v1)`: 객체의 자료형 확인

Python에서는 괄호 없이 쉼표만 사용해도 튜플을 만들 수 있다.

---

## 1.2 언패킹이란?

**언패킹(Unpacking)**은 여러 개의 값을 각각의 변수에 나누어 할당하는 것이다.

### 예제 코드

```python
v1, v2 = 10, 20

print(v1)
print(v2)
```

### 실행 결과

```text
10
20
```

### 작동 원리

```text
10, 20
│    │
▼    ▼
v1   v2
│    │
▼    ▼
10   20
```

오른쪽의 값들이 왼쪽 변수에 순서대로 할당된다.

# 2. 변수의 값 교환(Swapping)

**Swapping**은 두 변수의 값을 서로 교환하는 작업이다.

### 예제 코드

```python
v1, v2 = 10, 20

v2, v1 = v1, v2

print(v1, v2)
```

### 실행 결과

```text
20 10
```

### 실행 순서

```text
[교환 전]

v1 = 10
v2 = 20

       │
       ▼

v2, v1 = v1, v2

       │
       ▼

[교환 후]

v1 = 20
v2 = 10
```

### 핵심 개념

Python에서는 별도의 임시 변수 없이 두 변수의 값을 교환할 수 있다.

오른쪽 표현식들이 먼저 평가된 후 왼쪽 변수들에 할당되기 때문이다.

```python
a = 100
b = 200

a, b = b, a

print(a, b)
```

**실행 결과**

```text
200 100
```

# 3. 별표(*)를 이용한 확장 언패킹

## 3.1 확장 언패킹이란?

확장 언패킹(Extended Iterable Unpacking)은 여러 값을 변수에 분배할 때 `*`를 사용하여 나머지 값을 리스트로 받는 기능이다.

### 예제 1. 첫 번째 값만 분리

```python
v1, *v2 = 1, 2, 3, 4, 5

print(v1, v2)
```

**실행 결과**

```text
1 [2, 3, 4, 5]
```

**작동 원리**

```text
1, 2, 3, 4, 5
│  └────────┘
▼       ▼
v1      v2
1    [2,3,4,5]
```

- `v1`: 첫 번째 값인 1
- `*v2`: 나머지 값을 리스트로 받음

### 예제 2. 마지막 값만 분리

```python
*v1, v2 = 1, 2, 3, 4, 5

print(v1, v2)
```

**실행 결과**

```text
[1, 2, 3, 4] 5
```

### 예제 3. 마지막 두 값 분리

```python
*v1, v2, v3 = 1, 2, 3, 4, 5

print(v1, v2, v3)
```

**실행 결과**

```text
[1, 2, 3] 4 5
```

### 예제 4. 양 끝의 값 분리

```python
v1, *v2, v3 = 1, 2, 3, 4, 5

print(v1, v2, v3)
```

**실행 결과**

```text
1 [2, 3, 4] 5
```

### 예제 5. 앞의 두 값 분리

```python
v1, v2, *v3 = 1, 2, 3, 4, 5

print(v1, v2, v3)
```

**실행 결과**

```text
1 2 [3, 4, 5]
```

## 3.2 확장 언패킹 정리

| 코드 | v1 | v2 | v3 |
|---|---|---|---|
| `v1, *v2 = ...` | 1 | [2,3,4,5] | - |
| `*v1, v2 = ...` | [1,2,3,4] | 5 | - |
| `*v1, v2, v3 = ...` | [1,2,3] | 4 | 5 |
| `v1, *v2, v3 = ...` | 1 | [2,3,4] | 5 |
| `v1, v2, *v3 = ...` | 1 | 2 | [3,4,5] |

**주의사항**

하나의 할당 대상 목록에서 별표가 붙은 변수는 하나만 사용할 수 있다.

```python
# 잘못된 코드
# *a, *b = 1, 2, 3, 4
```

# 4. print() 함수와 출력 서식

## 4.1 print() 함수란?

`print()`는 데이터를 표준 출력으로 보내는 Python 내장 함수이다.

일반적으로 터미널에 값을 출력한다.

```python
print("안녕하세요")
print(123)
print(3.14)
```

**실행 결과**

```text
안녕하세요
123
3.14
```

---

## 4.2 format() 함수

`format()`은 데이터를 지정한 서식에 맞는 문자열로 변환한다.

### 예제 코드

```python
print(format(123.45678, '10.3f'))
print(format(123.45678, '10.3'))
```

### 실행 결과

```text
   123.457
     123.0
```

### 서식 분석

`10.3f`

- `10`: 최소 출력 폭 10칸
- `.3`: 소수점 아래 3자리
- `f`: 고정소수점 형식

`10.3`

- `10`: 최소 출력 폭 10칸
- `.3`: 유효 숫자 3자리
- 형식 생략 시 실수의 기본 표시 형식 적용

**중요한 차이**

`.3f`는 소수점 아래 자릿수를 지정하지만, `.3`은 기본 실수 표시 형식에서 유효 숫자의 개수를 지정한다.

# 5. 문자열 출력 서식

## 5.1 % 서식

문자열 안에 `%` 형식 지정자를 사용하면 값을 지정한 형식으로 출력할 수 있다.

### 예제 코드

```python
print(
    '서식에 의한 자료 출력 %s %d %f'
    % ('문자열', 5, 23.4)
)
```

### 실행 결과

```text
서식에 의한 자료 출력 문자열 5 23.400000
```

### 주요 서식 문자

| 서식 | 의미 | 예시 |
|---|---|---|
| `%s` | 문자열 형식 | 문자열 |
| `%d` | 정수 형식 | 5 |
| `%f` | 실수 형식 | 23.400000 |
| `%.2f` | 소수점 아래 2자리 | 23.40 |

---

## 5.2 f-string

f-string은 문자열 내부에 변수나 표현식의 결과를 직접 삽입하는 기능이다.

### 예제 코드

```python
name = "마우스"
price = 5000

print(f"이름:{name}, 가격:{price}")
```

### 실행 결과

```text
이름:마우스, 가격:5000
```

### 코드 분석

- `name`: 제품 이름을 참조하는 변수
- `price`: 제품 가격을 참조하는 변수
- `f`: 포맷 문자열을 나타내는 접두사
- `{name}`: name의 값을 문자열에 삽입
- `{price}`: price의 값을 문자열에 삽입

### 추가 예제

```python
name = "키보드"
price = 35000

print(f"제품명: {name}")
print(f"가격: {price:,}원")
```

**실행 결과**

```text
제품명: 키보드
가격: 35,000원
```

`{price:,}`는 천 단위 구분 쉼표를 표시한다.

# 6. 세미콜론(;)과 명령문

Python은 일반적으로 한 줄에 하나의 명령문을 작성한다.

```python
name = "마우스"
price = 5000
```

세미콜론을 사용하면 한 줄에 여러 단순 명령문을 작성할 수 있다.

```python
name = "마우스"; price = 5000

print(name, price)
```

**실행 결과**

```text
마우스 5000
```

하지만 가독성을 위해 각 명령문을 별도의 줄에 작성하는 것이 일반적이다.

## 6.1 긴 명령문의 줄바꿈

역슬래시(`\`)를 이용하면 명령문을 다음 줄로 연결할 수 있다.

```python
result = 10 + 20 + 30 + \
         40 + 50

print(result)
```

**실행 결과**

```text
150
```

그러나 괄호를 활용하면 역슬래시 없이도 줄을 나눌 수 있다.

```python
result = (
    10 + 20 + 30
    + 40 + 50
)

print(result)
```

이 방법이 일반적으로 가독성이 좋다.

# 7. print()의 end 매개변수

## 7.1 기본 출력

```python
print('abc')
print('def')
```

**실행 결과**

```text
abc
def
```

`print()`는 기본적으로 출력 끝에 줄바꿈 문자 `\n`을 추가한다.

## 7.2 end='' 사용

```python
print('abc', end='')
print('def')
```

**실행 결과**

```text
abcdef
```

`end=''`는 자동 줄바꿈을 제거한다.

## 7.3 공백으로 연결

```python
print('abc', end=' ')
print('def')
```

**실행 결과**

```text
abc def
```

### end 정리

| 코드 | 의미 |
|---|---|
| `end='\n'` | 줄바꿈 |
| `end=''` | 붙여서 출력 |
| `end=' '` | 공백으로 연결 |
| `end='-'` | 하이픈으로 연결 |

# 8. 산술 연산자(Arithmetic Operators)

산술 연산자는 숫자 데이터를 계산할 때 사용한다.

### 예제 코드

```python
print(5 + 3)
print(5 - 3)
print(5 * 3)
print(5 / 4)
print(5 // 3)
print(5 % 3)
print(5 ** 3)
```

### 실행 결과

```text
8
2
15
1.25
1
2
125
```

### 산술 연산자 정리

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `+` | 덧셈 | 5 + 3 | 8 |
| `-` | 뺄셈 | 5 - 3 | 2 |
| `*` | 곱셈 | 5 * 3 | 15 |
| `/` | 나눗셈 | 5 / 4 | 1.25 |
| `//` | 몫을 내림한 값 | 5 // 3 | 1 |
| `%` | 나머지 | 5 % 3 | 2 |
| `**` | 거듭제곱 | 5 ** 3 | 125 |

### 주의사항

`//`는 단순히 소수점 이하를 잘라내는 것이 아니다.

나눗셈 결과를 음의 무한대 방향으로 내림한다.

```python
print(-5 // 3)
```

**실행 결과**

```text
-2
```

# 9. 큰 정수 연산과 divmod()

## 9.1 큰 정수 연산

```python
print(123456789 ** 12)
```

Python의 `int`는 일반적인 고정 크기 정수형보다 큰 정수를 표현할 수 있다.

필요한 만큼 정밀도를 확장할 수 있지만 실제 메모리와 실행 시간에는 한계가 있다.

## 9.2 divmod() 함수

`divmod()`는 몫과 나머지를 동시에 반환한다.

```python
print(divmod(5, 3))
```

**실행 결과**

```text
(1, 2)
```

### 작동 원리

```text
5 ÷ 3
  │
  ├── 몫 = 1
  │
  └── 나머지 = 2

        │
        ▼

   divmod(5, 3)

        │
        ▼

      (1, 2)
```

결과는 튜플로 반환된다.

### 언패킹과 연결

```python
quotient, remainder = divmod(5, 3)

print("몫:", quotient)
print("나머지:", remainder)
```

**실행 결과**

```text
몫: 1
나머지: 2
```

앞에서 배운 언패킹을 활용한 예제이다.

# 10. 연산자 우선순위

하나의 표현식에 여러 연산자가 존재하면 Python은 연산자 우선순위에 따라 계산한다.

### 예제 코드

```python
print(3 + 4 * 5)
print((3 + 4) * 5)
```

### 실행 결과

```text
23
35
```

### 계산 과정

첫 번째 표현식:

```text
3 + 4 * 5

3 + 20

23
```

두 번째 표현식:

```text
(3 + 4) * 5

7 * 5

35
```

### 주요 연산자 우선순위

| 우선순위 | 연산자 | 의미 |
|---|---|---|
| 높음 | `( )` | 괄호로 묶은 표현식 |
| | `**` | 거듭제곱 |
| | `+x`, `-x` | 단항 부호 |
| | `* / // %` | 곱셈과 나눗셈 |
| | `+ -` | 덧셈과 뺄셈 |
| | `> < == !=` | 비교 연산 |
| | `not` | 논리 부정 |
| | `and` | 논리 AND |
| 낮음 | `or` | 논리 OR |

위 표는 주요 연산자만 정리한 것이다.

할당문에서 사용하는 `=`는 일반적인 이항 계산 연산자와 성격이 다르다.

### 같은 우선순위의 연산

일반적인 곱셈과 나눗셈 연산은 왼쪽부터 계산한다.

```python
print(20 / 5 * 2)
```

**실행 결과**

```text
8.0
```

거듭제곱은 오른쪽부터 결합한다.

```python
print(2 ** 3 ** 2)
```

**실행 결과**

```text
512
```

`2 ** (3 ** 2)`로 계산되기 때문이다.

# 11. 비교 연산자(Comparison Operators)

### 예제 코드

print(5 > 3)

### 실행 결과

True

### 비교 연산자 정리

|---|---|

# 12. 논리 연산자(Logical Operators)

논리 연산자는 조건식을 결합하거나 결과의 참·거짓을 반전한다.

## 12.1 and

두 조건이 모두 참이어야 참으로 평가한다.

```python
print(5 > 4 and 4 < 3)
```

**실행 결과**

```text
False
```

## 12.2 or

두 조건 중 하나라도 참이면 참으로 평가한다.

```python
print(5 > 4 or 4 < 3)
```

**실행 결과**

```text
True
```

## 12.3 not

논리적 참·거짓을 반대로 바꾼다.

```python
print(not(5 > 4))
```

**실행 결과**

```text
False
```

### 논리 연산 진리표

| A | B | A and B | A or B |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

### 추가 개념

Python에서 `and`와 `or`는 반드시 `True` 또는 `False`만 반환하는 것은 아니다.

```python
print(0 or 10)
print(5 and 20)
```

**실행 결과**

```text
10
20
```

연산 과정에서 피연산자 객체 자체를 반환할 수 있다.

# 13. 문자열 연산

Python에서는 문자열도 일부 연산자를 사용할 수 있다.

## 13.1 문자열 연결

```python
print('한' + '국' + '만세')
```

**실행 결과**

```text
한국만세
```

문자열의 `+` 연산자는 문자열을 연결한다.

## 13.2 문자열 반복

```python
print('한국' * 5)
```

**실행 결과**

```text
한국한국한국한국한국
```

문자열에 정수를 곱하면 해당 문자열이 반복된다.

### 주의사항

```python
# 오류가 발생하는 코드
# print('한국' + 5)
```

문자열과 정수를 직접 `+`로 연결할 수 없다.

```python
print('한국' + str(5))
```

**실행 결과**

```text
한국5
```

`str()`을 이용해 정수를 문자열로 변환하면 연결할 수 있다.

# 14. 복합 할당 연산자

복합 할당 연산자는 연산 결과를 다시 변수에 할당한다.

### 예제 코드

```python
a = 10

a = a + 1
a += 1

print('a는', a)
print(f'a는 {a}')
```

### 실행 결과

```text
a는 12
a는 12
```

### 실행 과정

```text
a = 10

   │
   ▼

a = a + 1

a = 11

   │
   ▼

a += 1

a = 12
```

### 복합 할당 연산자 정리

| 연산자 | 예시 | 의미 |
|---|---|---|
| `+=` | `a += 2` | 더해서 할당 |
| `-=` | `a -= 2` | 빼서 할당 |
| `*=` | `a *= 2` | 곱해서 할당 |
| `/=` | `a /= 2` | 나눠서 할당 |
| `//=` | `a //= 2` | 몫을 내림하여 할당 |
| `%=` | `a %= 2` | 나머지를 할당 |
| `**=` | `a **= 2` | 거듭제곱하여 할당 |

### 주의사항

Python에는 C나 Java의 `a++`, `a--`와 같은 증감 연산자가 없다.

일반적으로 다음과 같이 작성한다.

```python
a += 1
a -= 1
```

# 15. 단항 연산자와 부호 변경

단항 연산자는 하나의 피연산자에 적용된다.

```python
a = 12

print(a)
print(a * -1)
print(-a)
print(--a)
print(-(-a))
```

### 실행 결과

```text
12
-12
-12
12
12
```

### 코드 분석

- `a`: 현재 값
- `a * -1`: -1을 곱하여 부호 변경
- `-a`: 음의 부호를 적용
- `--a`: 단항 마이너스를 두 번 적용
- `-(-a)`: 음수에 다시 음의 부호를 적용

**중요한 점**

`--a`는 값을 감소시키는 연산이 아니다.

`-(-a)`와 같은 의미로 해석된다.

# 16. Boolean과 bool() 함수

## 16.1 Boolean이란?

Boolean은 참(True)과 거짓(False)을 나타내는 자료형이다.

Python에서는 `bool` 자료형으로 표현한다.

```python
print(type(True))
print(type(False))
```

**실행 결과**

```text
<class 'bool'>
<class 'bool'>
```

---

## 16.2 숫자의 Boolean 변환

```python
print(
    bool(123),
    bool(1),
    bool(-3.5),
    bool(True)
)
```

**실행 결과**

```text
True True True True
```

일반적인 숫자 자료형에서 0이 아닌 값은 True로 평가된다.

```python
print(
    bool(0),
    bool(0.0),
    bool(False),
    bool(None)
)
```

**실행 결과**

```text
False False False False
```

---

## 16.3 컬렉션의 Boolean 변환

```python
print(
    bool([]),
    bool({}),
    bool(set())
)
```

**실행 결과**

```text
False False False
```

비어 있는 리스트, 딕셔너리, 집합은 False로 평가된다.

### 추가 예제

```python
print(bool("Python"))
print(bool(""))
print(bool([1, 2, 3]))
print(bool([0]))
```

**실행 결과**

```text
True
False
True
True
```

`[0]`은 원소가 하나 존재하는 리스트이므로 True다.

### False로 평가되는 대표적인 값

| 값 | 결과 |
|---|---|
| `0` | False |
| `0.0` | False |
| `False` | False |
| `None` | False |
| `""` | False |
| `[]` | False |
| `{}` | False |
| `set()` | False |

### 핵심 개념

Python은 객체가 참인지 거짓인지 판단하는 규칙을 가지고 있다.

일반적으로 비어 있는 컬렉션이나 0에 해당하는 숫자는 False로 평가된다.

다만 사용자 정의 객체는 `__bool__()` 또는 `__len__()`의 동작에 따라 다르게 평가될 수 있다.

# 17. 이스케이프 문자(Escape Sequence)

## 17.1 이스케이프 문자란?

이스케이프 문자는 문자열 내부에서 특정한 의미를 표현하기 위해 사용하는 문자 조합이다.

주로 역슬래시(`\`)와 다른 문자를 조합한다.

### 대표적인 이스케이프 문자

| 문자 | 의미 |
|---|---|
| `\n` | 줄바꿈 |
| `\t` | 수평 탭 |
| `\\` | 역슬래시 자체 |
| `\'` | 작은따옴표 |
| `\"` | 큰따옴표 |
| `\b` | 백스페이스 |
| `\a` | 벨 문자 |

---

## 17.2 탭 문자

```python
print('aa\tbb')
```

`\t`는 수평 탭 문자다.

단순한 공백 하나가 아니라 출력 위치를 다음 탭 위치로 이동시키는 역할을 한다.

---

## 17.3 Raw String

문자열 앞에 `r`을 붙이면 대부분의 역슬래시를 일반 문자로 취급한다.

```python
print('aa\tbb')
print(r'aa\tbb')
```

첫 번째 문자열에는 탭 문자가 포함된다.

두 번째 문자열은 다음과 같이 출력된다.

```text
aa\tbb
```

---

## 17.4 백스페이스 문자

```python
print('aa\bbb')
print(r'aa\bbb')
```

첫 번째 문자열에서 `\b`는 백스페이스 제어 문자다.

터미널에 따라 앞 문자가 지워지거나 커서가 이동하는 등 표시 결과가 달라질 수 있다.

두 번째 문자열은 다음과 같이 출력된다.

```text
aa\bbb
```

---

## 17.5 줄바꿈 문자

```python
print('aa\nbb')
```

**실행 결과**

```text
aa
bb
```

`\n`은 줄바꿈을 의미한다.

### Raw String 비교

```python
print(r'aa\nbb')
```

**실행 결과**

```text
aa\nbb
```

Raw String에서는 `\n`이 줄바꿈으로 해석되지 않는다.

# 18. Windows 경로와 이스케이프 문자

Windows 파일 경로에서는 역슬래시를 자주 사용한다.

그러므로 Python 문자열에 경로를 직접 입력할 때 주의해야 한다.

### 잘못 해석될 수 있는 예제

```python
path = 'C:\new\test.txt'

print(path)
```

이 코드에서는 `\n`이 줄바꿈으로, `\t`가 탭으로 해석된다.

### 해결 방법 1. Raw String

```python
path = r'C:\new\test.txt'

print(path)
```

### 해결 방법 2. 역슬래시 두 번 사용

```python
path = 'C:\\new\\test.txt'

print(path)
```

### 해결 방법 3. 슬래시 사용

```python
path = 'C:/new/test.txt'

print(path)
```

세 가지 방법 모두 Windows 경로를 표현할 수 있다.

**주의사항**

Raw String도 모든 문자열 규칙을 무력화하는 것은 아니다.

예를 들어 역슬래시 하나로 끝나는 Raw String은 그대로 작성할 수 없다.

```python
# 잘못된 코드
# path = r'C:\new\'
```
